Mobius Device Lab - Bundled Toolchain Notices
=============================================

Mobius desktop packages contain command-line tools used only for local,
user-initiated Android and iOS development and device-management operations.
Exact versions, original download locations, archive hashes, build settings,
linkage, and per-file hashes are recorded in packaging/toolchain.lock.json and
in the manifest.json shipped beside each platform bundle. The exact license
texts named below are shipped in that bundle's licenses/ directory.

Mobius SSH/SFTP helper dependencies
-----------------------------------
The first-party Mobius helper provides only the SSH command, single-file SFTP,
and loopback port-forwarding operations generated by this application. It uses:

- golang.org/x/crypto v0.56.0 (BSD 3-Clause)
- github.com/pkg/sftp v1.13.11 (BSD 2-Clause)
- github.com/kr/fs v0.1.0 (BSD 3-Clause)
- golang.org/x/sys v0.47.0 on Windows (BSD 3-Clause)

Each applicable license and the Go project's accompanying PATENTS grant are
shipped in the target bundle. Exact source archives, Go checksums, first-party
helper source/tests, and target linkage are included in the companion source
archive.

Source and relinking material
-----------------------------
Every Release includes Mobius-Device-Lab_<version>_third-party-sources.tar.xz.
It contains the complete, hash-locked upstream sources listed above, the exact
license and NOTICE files, the go-ios patch, scrcpy's upstream build scripts,
Mobius preparation/verification scripts, and packaging/SCRCPY_REBUILD.md.
SOURCE_INDEX.json records target linkage and SHA256SUMS.txt covers every other
file in the archive.

Platform requirements not contained in the application
--------------------------------------------------------
Windows still requires Apple's Mobile Device USB driver/service for USB iOS
access. Linux requires working USB permissions and usbmuxd for USB iOS access.
Device trust, the jailbreak SSH server, AppSync/device-side package installers,
and Developer Disk Images remain properties of the user's authorized test
device or operating system. The desktop-side SSH/SFTP client is included in
every target package and does not depend on an operating-system OpenSSH client.
