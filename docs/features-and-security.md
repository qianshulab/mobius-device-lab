# 功能与安全边界

## 使用范围

Mobius 仅用于以下场景：

- 你拥有的设备和应用。
- 组织明确授权的开发、兼容性验证和调试设备。
- 已明确登记目标、时间范围、允许动作和数据处理方式的内部应用测试。

所有操作必须绑定于已确认的设备、应用和实验室网络。私网设备发现只用于寻找用户自有测试机，高级 Shell 和 Frida Server 只用于已授权的应用运行时调试。

## 当前安全控制

### 主机进程

- 常规外部工具以固定程序名和参数数组启动，不通过主机 shell。
- 配对码通过标准输入发送给 ADB，避免出现在主机进程参数列表。
- 常规命令有超时；超时后会尝试终止并回收直接子进程。
- 标准输出和错误输出使用有界通道读取并分别限制为 1 MiB，持续输出不会阻止超时检查。
- WebView 只获得 `src-tauri/capabilities/default.json` 中显式列出的命令。

### 应用包分析与安装

- APK/IPA 文件只能通过明确的本地绝对路径分析；界面使用系统原生文件选择器取得路径。
- 文件总大小、ZIP 条目数、实际解压字节数、plist、图标和 Mach-O 读取量均有上限。
- IPA 只接受唯一的 `Payload/<App>.app/Info.plist` 根应用，图标与主程序搜索限制在同一 App 目录，避免误选扩展或嵌套 App。
- APK 元数据优先由 `aapt2` 读取，再尝试 `apkanalyzer`；ZIP 级回退会在结果中明确标记，不能当作完整清单。
- MD5 是用户要求的文件标识和兼容字段，不应被当作软件真实性或供应链安全证明。
- Android 安装与 iOS `ideviceinstaller` 安装均使用参数数组调用，并完整服从设备现有的签名、配对、信任、越狱和 AppSync 验证条件。
- 导出 Android App 时会同时处理 base/split APK，目标文件名和包名经过校验；覆盖已有文件必须显式选择。
- 应用导出目录可在设置页预选；未设置时，每次导出都使用原生目录选择器让用户确认目标。
- Android 应用启动和停止使用固定参数；清除数据和卸载会锁定设备/包名并要求二次确认。系统应用在界面不可选，后端也会通过 Package Manager 分类再次拒绝。

### 网络扫描

- 只接受 RFC1918 私有 IPv4 地址。
- 自动发现优先实际 Wi-Fi/以太网，排除 VPN/TUN 和常见虚拟接口；若首选网段未发现 ADB，按优先级顺序尝试至多 4 个本机活动私网 `/24`。
- 高级模式显式填写的网段仍必须是检测到的本机活动 RFC1918 `/24`，拒绝任意其他私网或公网范围。
- 每次最多 16 个端口、64 个工作线程；同一进程中只允许一个扫描任务。
- 默认端口为 5555；候选会执行有限的 ADB 协议探测，并区分 ADB 端点与普通开放端口。
- 默认流程只对通过 ADB 协议确认的端点自动执行 `adb connect`；普通开放端口不会连接，扫描失败后仍可重试或改用手动地址。

自动发现只应用于用户已获授权的设备与局域网。共享 Wi-Fi 中仍可能存在不属于用户的主机；使用者必须确保当前物理网络属于测试范围。

### Android 文件

- 远端路径必须是绝对路径，且不能包含空段、`.`、`..` 或换行控制字符。
- 本地路径必须是绝对路径；上传源必须真实存在。
- 图形界面的删除接口只允许以下位置的子项：
  - `/sdcard/`
  - `/storage/emulated/<数字用户>/`
  - `/data/local/tmp/`
- 根目录或上述目录本身不能通过该删除接口移除。

当前路径范围检查是词法检查，设备端符号链接、绑定挂载或特殊文件系统仍可能把操作导向意外位置；不要在包含不受信任链接的目录中依赖它充当完整沙箱。这些限制也不适用于高级 shell 中由用户主动输入的命令。

### Android 代理

- Mobius 不会因为打开“网络”页、选中设备或创建 Reverse 而自动修改系统代理。
- USB Reverse 与 Android 系统代理是独立动作：默认按钮只建立同端口 ADB reverse，不会写系统代理，适合 Reqable 等自行管理代理设置的工具。
- 用户显式勾选或点击组合按钮后，才会在建立 Reverse 后把设备系统代理指向 `127.0.0.1`；LAN 模式则只执行明确填写的系统代理设置。
- 移除 Reverse 与恢复系统代理也是独立动作，避免清理隧道时意外覆盖另一个工具正在管理的代理状态。
- 每次开始受管设置时，后端会一次读取并保留 `http_proxy`、`global_http_proxy_host`、`global_http_proxy_port`、`global_http_proxy_exclusion_list` 和 `global_proxy_pac_url` 五个全局字段；不会只保存一个 `host:port` 字符串。
- 重复设置时，如果设备当前的整组快照仍等于 Mobius 上次设置后的快照，则保留最初的恢复基线。如果中间已有外部变更，一次新的显式“设置”只会在该新状态可安全恢复时把它作为新基线。
- 恢复按钮和正常退出都会先比较五个字段。只有当前整组状态仍等于 Mobius 写入后的快照时才恢复；任一字段被外部程序改动后，会留住该外部新值并报告冲突。
- 恢复“原先没有有效代理”时，先写入 `http_proxy=:0` 让 Android 清空内存中的代理状态并发送 `PROXY_CHANGE`，等待状态稳定后再按原样回写五个原始字段，保留“字段不存在”和“空字符串”的差异。
- 现有 PAC URL、非空排除列表或无法解析的静态代理形式无法通过该 ADB 接口可靠地重建；Mobius 会在写入任何新值前拒绝替换它们。
- 设置失败时会尝试回滚整组原状态。设备离线、主机崩溃或强制终止时无法保证清理成功，测试结束前仍应主动核对设备设置。

### Android 屏幕采集

- 投屏、截图和录屏统一从“设备”页进入，并始终携带明确的设备序列号。
- Android 设备在首屏默认启动连续内嵌视频，而不是另启一个 scrcpy 窗口或默认轮询截图。桌面宽度下，左侧是适配手机的竖向画面，右侧只放交互、截图与录屏操作，下方使用紧凑列表选择设备；跨页面切换当前设备统一使用顶部设备栏。实际画面旋转为横屏时再扩宽预览。
- 后端从已选 `scrcpy` 读取版本，定位应与该客户端版本匹配的 `scrcpy-server`，将它推送到一个随机命名的设备临时 jar，再用随机 SCID 的 ADB reverse 接收只含视频的 H.264 流。内嵌链路不启用 scrcpy 音频和控制通道；文件不兼容时启动会失败并进入降级。
- FFmpeg 将原始 H.264 转为 MJPEG。Rust HTTP 端口只绑定 `127.0.0.1`，只服务一个客户端，要求精确的随机会话路径、独立 128 位令牌和回环 Host，并拒绝外部 Origin。返回的画面明确禁止缓存。
- 每个序列号同时只保留一个受管流。暂停、重连、切换设备、离开页面、客户端断开、视频 EOF 或应用退出时，会尽力停止受管的 scrcpy Server 与 FFmpeg，关闭 socket，移除本会话 reverse，并删除对应的临时 jar。
- 完整的 scrcpy 安装（客户端 + 版本匹配的 Server）或 FFmpeg 不可用，或连续视频中断时，界面会明确降级到 `adb -s <serial> exec-out screencap -p` 的低频单帧 PNG 预览。单帧接口有 8 秒超时和 16 MiB 内联上限；页面隐藏时不请求新帧。
- 键鼠交互仍由用户显式点击后打开的独立 scrcpy 窗口承担，它不是默认预览路径。
- 截图先在设备生成受控临时 PNG，校验格式、尺寸与像素上限后，可写入系统剪贴板或用户选择的电脑目录。
- 录屏使用受控参数和 `--time-limit 0` 在设备持续生成 MP4；开始后界面显示计时，用户点击同一按钮时发送正常中断以完成封装、拉取并校验容器标识。切换设备、离开页面或退出应用也会自动走同一停止与保存流程；结果中的时长是实测值。成功或失败都会尽力清理 Mobius 创建的设备临时文件。
- 电脑端默认目录由设置页配置；未配置时保存操作会要求用户明确选择目录。

### Frida Server

- 用户必须自行提供普通文件，文件名以 `frida-server` 开头，大小不超过 512 MiB。
- 远端文件只能安装到 `/data/local/tmp/` 的直接子路径，默认使用不含 `frida` 的 `/data/local/tmp/mobius-agentd`；界面仍完整显示实际路径以便审计。
- 上传先写临时名称，设置权限成功后再原子替换目标文件。
- 已有受管 Server 运行时拒绝覆盖其二进制。
- Server 只能监听设备的 `127.0.0.1` 或 `::1`；设备端口和主机端口可分别设置，启动成功后自动创建不覆盖现有监听的 ADB forward。
- 停止时同时核对 PID、可执行文件真实路径和进程启动时间，避免误杀已复用 PID 的其他进程。
- 只管理本次 Mobius 会话启动并记录的进程。
- 如果启动后的映射或状态登记失败，后端会回滚；回滚不完整时仍保留资源记录，供显式停止或退出清理重试。

Mobius 不会自动 root 设备。量产 Android 通常需要用户已有的 root 方案，或在得到授权的应用中使用 Frida Gadget。

## iOS 的实际限制

当前产品范围只考虑用户拥有或获准测试的越狱 iOS 设备。已经实现设备枚举、libimobiledevice 固定主机操作、基础信息、IPA 分析/安装、受管端口隧道、SSH 文件管理、会话绑定诊断和 Frida Server 生命周期；界面不会把 Android 操作错误发送给 iOS。这些 iOS 适配器遵守以下边界：

- 非越狱 iOS 的 AFC 通常只暴露媒体区域或启用了文件共享的 App 文档容器，不是系统根文件系统。
- USB 模式通过 `iproxy` 建立 `127.0.0.1` 回环隧道，并固定到当前设备 UDID；可让系统自动选择空闲主机端口。LAN 模式只接受用户明确填写的私网、回环或链路本地字面 IP。
- `网络` 页中的独立受管隧道只使用回环地址：USB `iproxy` 只支持本机 `127.0.0.1:主机端口` → 指定 UDID 的设备端口；SSH `-L` 提供本机→设备，SSH `-R` 提供设备 `127.0.0.1:设备端口` → 本机 `127.0.0.1:主机端口`。`iproxy` 反向请求会被拒绝；SSH 两个方向都要求已验证会话，设置 `ExitOnForwardFailure=yes` 并禁用 `GatewayPorts`。
- 隧道列表只记录 Mobius 直接启动的子进程，上限为 64 条；停止按钮按不可猜测的隧道 ID 移除精确记录，不扫描、不杀掉其他程序启动的 `iproxy` / `ssh`。关闭 SSH 会话会停止与其 `sessionId` 绑定的隧道；独立 USB `iproxy` 由用户手动停止或在应用退出时清理。应用退出会停止所有仍受管的 iOS 隧道。
- 认证支持账号密码和用户选择的本地私钥。密码通过专用 `SSH_ASKPASS` helper 仅传给当次 OpenSSH 子进程，不进入命令行、日志、本地设置或凭据文件；Rust 原生层的密码副本会主动清零，界面值在切换设备时重置。私钥模式以批处理、公钥认证和指定身份运行。主机密钥记录在应用私有的 `known_hosts` 文件中。
- 每个会话必须声明一个或多个允许目录，拒绝根目录 `/`。会话建立时会取得远端规范路径；列表、上传、下载、新建和删除都会再次检查边界与符号链接，且允许根本身不可删除。
- 上传、下载覆盖已有文件必须显式选择；目录删除必须显式使用递归操作。退出应用时会停止仍受管的 `iproxy` 子进程和 SSH 会话状态。
- 越狱设备能开放更高权限，风险和数据暴露也更大；Mobius 只使用用户明确提供的现有凭据和设备环境。
- Windows 依赖 Apple Mobile Device USB 驱动；Linux 通常依赖 usbmuxd 和 udev 规则。
- `idevice_id -l/-n` 合并 USB 和已配对网络连接，同一 UDID 的 USB 通道优先。内嵌屏幕与截图只调用 `idevicescreenshot -u <精确 UDID>`，网络通道额外携带 `-n`。
- 调试页的 libimobiledevice 分组只有四个固定、只读操作：`ideviceinfo -u <UDID>`、`idevicepair -u <UDID> validate`、`ideviceinstaller -u <UDID> list --all` 和 `idevicesyslog -u <UDID> --no-colors`。已配对网络设备会额外携带 `-n`；后端不接受程序名、子命令或任意参数。
- 前三个主机操作默认最多运行 10 秒；`idevicesyslog` 默认采样 5 秒，所有操作的可调整超时都被限在 250 毫秒至 30 秒。标准输出上限 256 KiB、错误输出上限 16 KiB，会移除控制字符并明确标记截断。日志采样窗口到期被视为正常完成，不会留下常驻日志子进程。
- screenshotr 需要设备已配对、信任并挂载匹配的 Developer Disk Image。返回文件在私有临时目录验证 PNG 签名、尺寸、像素数和容量后，才会进入界面、剪贴板或用户目录。
- 手工登记的 `ios-ssh:*` 端点没有 lockdown/screenshotr 配对上下文，后端在调用屏幕工具前就会拒绝。这不影响该设备的 SSH 文件、应用、诊断和 Frida 功能。
- iOS Frida Server 只能由已验证的 Root SSH 会话启动，绑定设备回环地址并用本机回环 SSH forward 访问；停止时只处理当前会话记录的 PID、路径和隧道。
- iOS 应用管理只探测固定路径中已安装的 `appinst` / `ipainstaller`，不下载或安装工具。IPA 先在本机验证结构，再上传到当前 SSH 会话的中性临时路径，安装成功或失败都尽力清理。
- iOS 应用清单只遍历编译时固定的系统/用户应用根目录，仅返回顶层 `.app` 的有界元数据。导出前会再次校验规范路径和 Bundle ID。
- iOS 导出结果是用于开发分析的 `.app` `tar.gz`，不是 IPA，不保证可安装，不判定或改变二进制加密状态，不重建签名/描述文件。
- 越狱 SSH 系统诊断是另一组固定操作，只接收 `overview / processes / tools / syslog` 四个枚举值，不与上述 libimobiledevice 按钮混用。工具检测只检查编译时固定绝对路径的可执行文件状态，不启动被检测工具；日志限制为 20–400 行，成功与错误文本分别限长并移除控制字符。
- Respring 与重启是独立、固定的 Root 动作。后端先签发 30 秒有效、绑定会话/动作/SSH 端点与主机标识的一次性确认票据；界面展示实际 SSH 目标，执行时后端再次比对全部快照并消费票据。

## 产品功能白名单

- Android：ADB 配对/连接、当前私网 `/24` 设备发现、设备信息、APK 解析/安装/导出、应用启动/停止/清理/卸载、受限文件、投屏/截图/录屏、端口映射、系统代理、固定系统观察、高级 Shell 和 Frida Server 生命周期。
- 越狱 iOS：USB/已配对网络识别或手动私网 SSH、libimobiledevice 固定信息/配对/应用/日志按钮、屏幕采样预览/PNG 截图、IPA 解析/安装、USB `iproxy` 本机转发、SSH `-L` / `-R` 回环隧道、受限文件、应用清单、`.app` 开发分析归档、固定 SSH 诊断、明确确认的设备重启动作和 Frida Server 生命周期。
- 电脑端：工具链健康检查、默认目录/网络参数配置、当前会话活动记录与受管资源清理。

图形界面和 Tauri 能力清单只公开上述功能及它们所需的固定参数。

## 使用与工程限制

- 外部工具本身或其供应链被篡改。
- 用户在高级 shell 中执行破坏性命令。
- Root/越狱设备与测试网络、主机之间的高权限连接风险。
- 设备调试授权长期保留或 ADB 5555 暴露在不可信网络。
- 日志、截图和拉取文件中包含的隐私或凭据。
- 当前预览版尚未提供完整持久化审计日志、团队权限控制和工具包自动签名验证。
- 当前源码的受控工具目录没有附带第三方二进制，包括 `scrcpy-server` 与 `ffmpeg`；如果发行方自行加入工具，必须独立完成许可证、NOTICE/SBOM、来源和 SHA-256 审核，不能把“可被解析”当作“已验证安全”。
- 当前界面已使用原生文件选择器，但后端仍接收绝对主机路径，尚未实现由原生选择器签发、短时有效且一次性的路径授权；渲染器边界被破坏时，仅有对话框并不足以保护主机上的其他可访问文件。
- 进程超时目前以直接子进程为边界，尚未在 Unix 使用独立进程组、在 Windows 使用 Job Object 管理整个后代进程树。

## 推荐实验室做法

1. 使用隔离 VLAN 或专用热点，不在公共 Wi-Fi 开启传统 ADB TCP 5555。
2. 为测试设备准备可恢复快照或完整备份。
3. 仅在需要时启用 root、越狱、代理和端口映射，用完立即恢复。
4. 为 Frida Server 校验来源、版本、ABI 和文件哈希。
5. 不把配对码、令牌、证书私钥或原始敏感日志提交到仓库。
6. 发布包启用代码签名、公证、更新签名，并生成第三方许可证清单和 SBOM。
